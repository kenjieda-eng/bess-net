## (3) データ形・画面案・否定テスト案（便 I 用）

### データ形（案）`src/data/balancing-rules.ts`

便の案に、研究で要った 3 つ（`title`・`reasonQuote`・`batteryNote`）と、予定・データ待ちの扱いを足す。値は data.json の `rows` から生成する（手で写さない＝T2 と同じ型の生成スクリプト `scripts/gen-balancing-rules.ts`）。

```ts
type BalancingRuleKind = 'cap' | 'procurement' | 'product' | 'guideline' | 'battery';
type BalancingProduct = 'primary' | 'secondary-1' | 'secondary-2' | 'tertiary-1' | 'tertiary-2' | 'composite';
export interface BalancingRule {
  id: string;                       // 'A-3' など（data.json の id のまま）
  kind: BalancingRuleKind;
  title: string;                    // 当サイトの要旨（因果の語を入れない・公式呼称）
  announcedOn: string;              // 公表日 YYYY-MM-DD（一次の告知・資料の日付）
  effectiveFrom: string | null;     // 適用日（実需給日・受渡日）。一次で日単位が取れないものは null（予定・未決定は status で）
  status: 'effective' | 'scheduled' | 'undecided';  // C-9 同時市場＝undecided・B-28 二次①広域調達＝scheduled
  products: BalancingProduct[];     // 公式呼称は表示側で（一次調整力…複合商品）
  before: string;                   // 一次の逐語（長いものは画面では開閉欄）
  after: string;
```
