## 5. データ品質ノート

- **パースエラー**: 0件（完全パース成功）
- **配電用変電所の運用容量 > 設備容量**: 多数（例: 設備38MW → 運用39MW）  
  → PDFの台数基準の計算誤りではなく、原資料の仕様（変圧器並行等）
- **N-1可能量=0 の変電所**: 常磐66kV変電所（容量=0MW。形式上「可」だが実質ゼロ）
- **22kV変電所の予想潮流**: `None`（PDFに"-"記載）
- **上位系設備フィールド**: 文字列が末尾で切れている場合あり（pdfplumberのセル幅制限）

## 6. Phase 2 への引き渡し事項

### PDF取得先（TEPCO各県）
- URL体系: `https://www.tepco.co.jp/pg/consignment/system/` → 各県PDF
- 茨城と同じ形式が関東13都県に適用される（想定）

### スクリプトファイル
- `scripts/experimental/tepco/parse_tepco.py` — パーサ（`PDF`変数を変更するだけで他県対応可能）
- `scripts/experimental/tepco/explore_pdf.py` — 構造確認用
- `scripts/experimental/tepco/tepco_ibaraki.json` — 茨城県出力（137変電所 + 159送電線）

### Phase 2 推奨事項
1. 13都県のPDF一括ダウンロード
2. `parse_tepco.py` の `PDF` / `OUT` を県別にループ
3. `tepco_ibaraki.json` の構造で全県を結合 → `tepco_all.json`
4. `external_id` として `変茨城県 154kV 1` 等のIDを活用
5. 本番 `src/data/substations/index.json` への統合は Phase 3

### 留意点
- 送電線（transmission_lines）はbess-netスキーマに現状なし → Phase 2以降で設計
- 配電用変電所117件は現在のbess-netに存在しない（=新規追加候補）
- 基幹変電所は既存データとの突合作業が必要（同一変電所の重複排除）
